# Consent Ledger — especificação inicial

O sistema não deve usar consentimento como base para autenticação ou tramitação essencial. Se forem adicionadas finalidades opcionais (marketing, analytics ou compartilhamento opcional), registrar: titular, finalidade específica, versão do texto, data/hora, origem, prova apresentada, status e revogação.

Regras: consentimento separado por finalidade, não pré-marcado, revogável e sem impedir o serviço essencial (LGPD arts. 7º, I, 8º e 9º).
